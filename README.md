# TaskManager - Drag & Drop Board

A Kanban-style task management desktop application. It's designed to help organize workflows by moving tasks between "To Do", "In Progress", and "Done" columns using a Drag & Drop interface.

## Technologies Used
* **Language:** C#
* **Framework:** .NET / WPF
* **UI Design:** XAML

## Features
* **Drag and Drop Interface:** Move tasks between different status columns easily.
* **Deadline Tracking:** Tasks overdue or due today are highlighted.
* **Smart Notifications:** The app checks deadlines on startup and alerts you about overdue tasks.
* **Data Persistence:** All tasks are saved locally and reloaded when the app starts.
* **One-Click Cleanup:** Clear all completed tasks from the board and database.
